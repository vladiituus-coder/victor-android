# Víctor flotante (fase 1)

Treecko camina flotando sobre otras apps. Toque: reacciona. Doble toque: abre el juego. Arrastrar: lo movés.

Cómo obtener el APK: subí estos archivos a un repositorio de GitHub. En la pestaña Actions corre
"Build APK". Cuando termina (tilde verde), entrá a esa ejecución y descargá el artefacto "victor-apk".
